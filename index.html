Знакомство с миром HTML

Что такое HTML?

HTML - это язык разметки, который используется для создания структуры веб-страниц. С его помощью можно размещать текст, изображения, заголовки и другие элементы.

HTML является основой большинства сайтов. Он помогает браузеру понять, как организовать и отобразить содержимое страницы.

Основные HTML-теги

<h1> — главный заголовок страницы.

<p> — текстовый абзац.

<br> — перенос строки.

<img> — добавление изображения.
